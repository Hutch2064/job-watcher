# Source review

The watchlist contains only employer ATS JSON sources validated by the collector, not an assertion that other employers lack openings. It is a starting point and not an exhaustive audit of every career site. Source status is checked at each run. The user's requested names that map to current watchlist sources are BlackRock/iShares, Invesco, Fidelity, Dimensional/DFA, T. Rowe Price, State Street, Thrivent, AllianceBernstein, Jane Street, GMO, Oakmark, Avantis and WisdomTree UK; Hartford's company-wide board is also included, rather than a claim it is restricted to Hartford Funds. Other additions are in the README. Parent boards can include businesses beyond the named fund brand.

The Franklin Templeton Workday endpoint returned an empty list in the initial probe even though its careers site has advertised postings; that discrepancy needs investigation before treating the response as a reliable complete board. Eventide's investment management careers site lists jobs on its own site, but an anonymous ATS JSON feed has not been verified. VanEck and Calamos link to UKG boards; their JSON feeds have not been validated here. Allspring has a careers page whose feed has not been validated. Global X links to an Ashby board, but its public JSON endpoint returned HTTP 403 during the local check.

The following requested names have not been individually verified and should not be interpreted as unavailable: YieldMax, Tuttle Capital, Overlay Shares, X ETFs, Corgi, Tima, HCM, Schwab, Defiance, Direxion, FT Vest, Nios, Simplify, Rareview, Roundhill, Vega Shares, Logan Capital, IMGP, Bitwise, Morgan Stanley and Goldman Sachs. Some spoken names may need confirmation before reliable identification. Research and additional provider adapters remain necessary to assess these firms individually. No substitute aggregator or HTML scraping is represented as their employer board.
